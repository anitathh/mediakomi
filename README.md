# Медиакоми — угадай цену квартиры 🏠

Мобильная игра по данным объявлений о продаже квартир в Республике Коми (Авито).
Сервис показывает фотографии квартиры — игрок двигает бегунок и называет свою цену,
после чего узнаёт реальную цену, разницу и заработанные баллы.

## Как играть

1. На старте нажмите **«Запустить игру»**.
2. 10 раундов: листайте галерею фотографий, двигайте бегунок цены и жмите **«Оценить»**.
3. После каждого раунда — реальная цена, разница, баллы и ссылка на объявление.
4. В конце — итоговый балл и типаж игрока:
   - 🧑‍🎓 **Жадный студент** — вы стабильно называли цену ниже реальной;
   - 🤝 **Адекватный квартирант** — ваши оценки совпадали с рынком;
   - 💸 **Транжира** — вы стабильно завышали цену.

## Балльная система

За каждый раунд начисляется до **100 баллов** по формуле:

```
баллы = max(0, round(100 × (1 − |ваша цена − реальная цена| / реальная цена)))
```

- Точное попадание — 100 баллов, промах в 2 раза и больше — 0.
- Максимум за игру: **1000 баллов**.
- Типаж считается по среднему относительному отклонению ваших оценок (±10%).

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `mediakomi`).
2. Загрузите в него все файлы из этой папки (`index.html`, `style.css`, `app.js`, `data.js`, `img/`, README):

   ```bash
   git init
   git add .
   git commit -m "Медиакоми: игра-угадайка цен на квартиры"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/mediakomi.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Deploy from a branch → main / (root) → Save**.
4. Через минуту игра будет доступна по адресу
   `https://<ваш-логин>.github.io/mediakomi/`.

Сайт полностью статический (без сборки и зависимостей) — GitHub Pages работает из коробки.

## Локальный запуск

Просто откройте `index.html` в браузере или выполните:

```bash
python3 -m http.server 8080
```

и откройте <http://localhost:8080>.
